Dados neste dispositivo

As escalas salvas neste navegador ficam neste dispositivo. Elas não são sincronizadas. Limpar os dados do navegador ou desinstalar a PWA pode apagá-las; guarde um backup antes.

O backup v2 guarda as escalas deste navegador e as referências de início confirmadas neste dispositivo, inclusive as usadas com modelos e escalas da API local. Cada referência leva nome, tipo e parâmetros para ser associada à configuração certa; o arquivo não copia o catálogo completo da API nem a consulta ativa. Ao importar, mostramos o efeito sobre as referências e a consulta guardada antes de substituir. Backups v1 continuam aceitos; se uma escala antiga não tiver referência, será preciso informá-la uma vez.

O protótipo de widget Android ainda lê o formato v1. Use o botão de exportação compatível e informe a mesma data de início manualmente no Android. Ele não acessa automaticamente os dados do Chrome.

Leia a Política de Privacidade e os Termos de Uso antes de compartilhar um backup. O arquivo baixado fica sob seus cuidados.

Verificando escalas...

Exportar backup

Baixe o formato v2 para restaurar escalas e referências confirmadas. A opção v1 serve somente para o protótipo de widget e não inclui referências.

Importar backup

Escolha um backup deste Simulador (até 512 KB e 200 escalas). Primeiro mostramos a substituição; nada é gravado ao selecionar o arquivo.

Como instalar no celular

No Android, abra a demo no Chrome e use Instalar app no menu caso o botão de instalação não apareça. No iPhone, abra no Safari e escolha Compartilhar → Adicionar à Tela de Início.

Visite online uma vez e aguarde o carregamento completo antes de testar sem conexão.

Quando aparecer Atualização disponível, escolha Atualizar agora ou Mais tarde. A atualização da PWA não apaga as escalas. O ícone da tela inicial do Android pode levar mais tempo para mudar e depender de uma confirmação do Chrome.
