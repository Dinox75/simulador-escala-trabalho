ARMAZENAMENTO LOCAL

Dados neste dispositivo

As escalas salvas neste navegador ficam neste dispositivo. Elas não são sincronizadas. Limpar os dados do navegador ou desinstalar a PWA pode apagá-las; guarde um backup antes.

Escalas da API local são separadas e não entram neste backup. O arquivo v1 guarda as configurações cadastradas, mas não a consulta guardada, sua data e hora de início. Ao mudar de aparelho ou importar um backup antigo, confira e guarde novamente o início do ciclo.

O protótipo de widget Android é separado da PWA. Para usá-lo em testes, escolha este backup no aplicativo Android e informe novamente o início do ciclo. Ele não acessa automaticamente os dados do Chrome.

Leia a Política de Privacidade e os Termos de Uso antes de compartilhar um backup. O arquivo baixado fica sob seus cuidados.

Escolha um backup deste Simulador (até 512 KB e 200 escalas). Primeiro mostramos a substituição; nada é gravado ao selecionar o arquivo.

Uma versão nova está pronta. Feche as páginas abertas do Simulador e abra o aplicativo novamente; seus dados locais não são apagados pela atualização.

Como instalar no celular

No Android, abra a demo no Chrome e use Instalar app no menu caso o botão de instalação não apareça. No iPhone, abra no Safari e escolha Compartilhar → Adicionar à Tela de Início.

Visite online uma vez e aguarde o carregamento completo antes de testar sem conexão.
