Termos de uso

Uso responsável da demo.

Esta página apresenta uma simulação para fins educacionais, técnicos e demonstrativos. Os resultados devem ser conferidos antes de qualquer uso real.

1. Finalidade

O simulador é um projeto de estudo e portfólio. Ele demonstra cálculos de escala com base em dados informados pelo usuário, sem substituir sistemas oficiais de RH, folha, ponto ou gestão corporativa.

2. Conferência obrigatória

Antes de usar qualquer resultado em contexto real, confira com a empresa, liderança ou documento oficial da escala. A demo ajuda na visualização, mas não deve ser a única fonte de decisão.

3. Dados locais e API local

Na versão pública, a demo pode funcionar parcialmente com dados locais ou fallback visual. Quando executada com a API FastAPI local, as escalas cadastradas são enviadas para o backend local em http://127.0.0.1:8000.

Este projeto não envia dados para uma API pública de produção. A integração atual é voltada para ambiente local de desenvolvimento.

4. Limitações do cálculo

Regras especiais como feriados, banco de horas, trocas de turno, afastamentos, férias, faltas, horas extras e exceções operacionais ainda não fazem parte do cálculo padrão.

5. Limitação da API atual

A simulação pela API funciona com modelos prontos, como 6x3, 5x2, 4x2, 12x36 e turnos rotativos definidos no projeto. Escalas personalizadas salvas ainda não são simuladas por nome pela API nesta versão.

6. Evolução do projeto

Novas versões podem alterar textos, interface, estrutura de dados, endpoints e comportamento da demo. O objetivo é evoluir com testes, documentação e melhorias graduais.

7. Responsabilidade

O uso da ferramenta é livre para estudo e avaliação. Em caso de uso profissional, recomenda-se validação técnica, jurídica e operacional antes de qualquer implantação real.

8. Privacidade nesta demo

Evite inserir dados pessoais sensíveis ou informações reais de colaboradores durante testes. Use nomes fictícios ao testar cadastros de escala na API local.

Aviso rápido

Use a demo como apoio visual, não como regra oficial.

O projeto demonstra lógica, arquitetura e integração técnica. Para escala real de trabalho, sempre confirme com documentos oficiais ou responsáveis pela gestão da escala.
