Política de Privacidade

Simulador de Escala de Trabalho · Atualizada em 22 de outubro de 2026

Esta política descreve a demo web e o protótipo separado de widget Android. O projeto é independente e está em desenvolvimento. Para dúvidas ou solicitações sobre privacidade, escreva para vibylima75@gmail.com.

1. Dados digitados e guardados no dispositivo

Você pode informar nome e tipo de escala, períodos de trabalho e folga, sequência de turnos, datas de início e horários de consulta. A demo usa esses valores para calcular e mostrar status, calendário, comparação e relatório. Na origem pública, as configurações das escalas que você salva, a consulta que você decide guardar com seu início confirmado e a preferência de tema ficam no armazenamento local do navegador. O backup v1 inclui apenas os cadastros de escalas; não inclui o início da consulta guardada. Não há conta nem sincronização pública entre dispositivos.

O cache da PWA guarda páginas, scripts, estilos, manifesto e ícones para uso offline. Ele não é um banco de escalas. Limpar os dados do site, trocar de navegador ou dispositivo, ou desinstalar a PWA pode remover as escalas locais. O comportamento da desinstalação depende do navegador e do Android; faça backup antes.

2. Backup e exclusão

Em Dados locais, você pode baixar um JSON com as escalas salvas e importar um arquivo após validação, prévia e confirmação. O download é iniciado por você; o projeto não recebe o arquivo. Guarde-o em local escolhido por você e proteja-o conforme o conteúdo. A importação substitui as escalas deste navegador, sem alterar a API local ou outros backups.

Para apagar uma escala, use Minhas escalas no simulador. Para apagar todas as escalas, preferência de tema e cache deste site, use as configurações do navegador para remover os dados de dinox75.github.io. Arquivos JSON já baixados precisam ser apagados separadamente por você. Dados importados no protótipo Android ficam no armazenamento privado do aplicativo e podem ser removidos pelo botão de limpeza nele ou pela desinstalação; não são lidos automaticamente do Chrome.

3. Hospedagem, API opcional e contato

Ao abrir a demo pública, o navegador solicita arquivos ao GitHub Pages. O GitHub informa que registra o endereço IP de visitantes do Pages para segurança; outros dados técnicos seguem sua declaração de privacidade. O projeto não recebe os nomes e parâmetros das escalas salvas no navegador por meio dessas solicitações e não tem painel próprio de análise de uso.

Se você executar a API FastAPI em seu computador, as requisições da demo local podem enviar configurações de escalas a essa API. Ela salva em JSON por padrão ou em PostgreSQL se você configurar essa opção. A API não tem autenticação nem separação de usuários e não é oferecida como serviço público. Dados da API são separados dos dados deste navegador e do backup web.

Se você escrever ao contato público, o endereço de e-mail e o conteúdo que decidir enviar serão processados pelo serviço de e-mail usado na comunicação. Evite incluir dados sensíveis ou de terceiros. Você pode pedir esclarecimentos ou solicitar a exclusão de mensagens enviadas; a resposta dependerá do que estiver sob controle deste projeto e das regras do provedor de e-mail.

4. Recursos ausentes e mudanças

O código atual não usa anúncios, SDK de análise de uso, notificações push nem acesso à localização. O protótipo Android importa somente o backup que a pessoa escolhe e mantém a escala selecionada no armazenamento do próprio aplicativo, sem conta ou servidor. Mudanças futuras de dados ou integrações exigirão revisão desta política.

Esta página será atualizada quando o funcionamento mudar de modo relevante, com nova data e histórico no repositório. Não há aviso automático dentro da versão atual. Consulte também os Termos de Uso.
