Sobre o projeto

Um projeto de portfólio com problema real, evolução incremental e foco em usabilidade.

O Simulador de Escala de Trabalho nasceu como um projeto Python de linha de comando para praticar fundamentos importantes: datas, funções, validações, JSON, testes e organização de código.

A evolução transformou a lógica em uma demo web, depois em uma base com POO, Service, Repository, PostgreSQL e, agora, uma API FastAPI consumida pela interface.

Objetivo

Transformar uma dúvida recorrente em uma solução clara.

A pergunta central é simples: hoje eu trabalho, folgo ou estou em qual turno? O projeto responde isso usando regras de ciclo, datas, turnos rotativos e uma interface visual.

Para o colaborador

Facilita a visualização de trabalho, folga e turno em datas específicas.

  • Consulta rápida por data.
  • Próximos dias em linha do tempo.
  • Calendário visual.

Para a empresa

Serve como base para reduzir dúvidas operacionais e organizar modelos de escala.

  • Modelos reutilizáveis.
  • Menos retrabalho de conferência.
  • Base para painel futuro.

Para portfólio

Demonstra evolução real de projeto, arquitetura, testes, API e documentação.

  • Python e FastAPI.
  • POO, Service e Repository.
  • JSON, PostgreSQL e Pytest.
Evolução

O projeto cresceu por versões, sem pular etapas.

Cada versão adicionou uma camada nova sem abandonar a base anterior.

v0.1 → v0.4

Base do simulador

Cálculo por dias, menu, validações, cadastro e persistência inicial.

v0.5 → v0.7

Turnos, modelos e demo inicial

Turno rotativo, modelos predefinidos, escala real de 24 dias e interface web demonstrativa.

v0.8 → v0.10

Arquitetura e apresentação

POO, Service, Repository, PostgreSQL e site com páginas separadas.

v0.11 → v0.13

API e integração

FastAPI, endpoints HTTP, CRUD de escalas e demo consumindo API local.

v0.14

Produto em evolução

Demo pública sem backend, escalas salvas simuláveis e integração opcional com API local. Login e deploy ficam para versões futuras.
